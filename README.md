# SoftGrowTech — Internship Management Portal

A simple and responsive web application designed for interns to track tasks, submit work, and monitor their learning progress during their internship at SoftGrowTech.

---

## 📌 Project Overview

This portal helps interns stay organized throughout their internship journey with an easy-to-use interface for managing daily tasks and project milestones.

---

## ✨ Key Features

- **User Authentication:** Simple Sign Up and Sign In system.
- **Intern Dashboard:** Quick summary of active tasks, submitted work, and overall completion rate.
- **Task Management:** View assigned tasks, requirements, and deadlines.
- **Project Submissions:** Easy form to submit project links (GitHub, live preview) and notes.
- **Progress Tracking:** Visual progress metrics to keep track of completed tasks.
- **Dark / Light Mode:** Clean UI with a built-in theme toggle.
- **Responsive Layout:** Works on mobile, tablet, and desktop devices.

---

## 🛠️ Technologies Used

- **HTML5** — Page structure and semantic layout
- **CSS3** — Styling, animations, and responsive design
- **JavaScript (ES6)** — Dynamic functionality and client-side logic
- **Lucide Icons** — Modern vector icons
